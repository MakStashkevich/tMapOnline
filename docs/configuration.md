# Конфигурация и блоки сайта

Конфиг YAML версии `1` валидируется в `terraria_viewer/config.py`; отсутствующие поля получают defaults. Перезапуск нужен после изменения файла.

```yaml
site:
  pages:
    world_map: { enabled: true }
  sections:
    world: true
    players: true
    bosses: true
    server: true
    activity: true
  modules:
    world_map.exploration: true
    world_map.entities: true
```

Параметры истории и частоты телеметрии:

```yaml
storage:
  death_retention_seconds: 3600 # 0 — хранить смерти без ограничения
telemetry:
  player_position_interval_ticks: 6 # Позиции игроков, 6 тиков ≈ 100 мс
  entity_interval_ticks: 6 # NPC, боссы, монеты и пилоны
  map_capture_interval_ticks: 30 # Цветные данные карты вокруг игроков
  map_tile_update_interval_ticks: 1 # Изменившиеся тайлы и стены, включая взрывы
  world_scan_interval_ticks: 1 # Пауза между обработкой чанков сканера
  browser_live_poll_interval_ms: 50 # Частота лёгкого запроса живых данных
  browser_map_poll_interval_ms: 5000 # Частота получения обновлений карты
  browser_debug_poll_interval_ms: 1000 # Частота карты при открытых настройках debug
```

Срок очистки применяется и к уже сохранённым смертям. Для каждого события смерти мод отправляет устойчивый ID и ждёт подтверждения Python-сервиса; при обрыве соединения событие остаётся в очереди и передаётся повторно.

Интервалы телеметрии задаются в игровых тиках и передаются локальному tModLoader через переменные окружения при запуске из Viewer. `1` означает каждый игровой тик. Частота браузера задаётся в миллисекундах. Большие данные карты запрашиваются отдельно и реже, а маршрут, позиции, сущности, смерти и разреженные изменения тайлов идут через `/api/world-map/live` без повторной отправки чанков и всей истории.

Полный набор ключей см. в корневом `config.yaml`.

| Ключ                                       | Назначение                                                                                                                     |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| `site.pages.world_map.enabled`             | Включает Viewer и маршрут страницы карты.                                                                                      |
| `site.sections.*`                          | Включает вкладки данных: мир, игроки, боссы, сервер и нагрузка. Данные вкладки запрашиваются при её открытии.                  |
| `site.modules.world_map.*`                 | Включает отдельные слои карты: исследование, маршруты, игроки, сущности, монеты, пилоны, точку появления, подсказки и отладку. |
| `storage.death_retention_seconds`          | Сколько секунд хранить метки смертей; `0` отключает автоматическую очистку. По умолчанию 3600.                                 |
| `telemetry.player_position_interval_ticks` | Частота позиций игроков в игровых тиках. Для локального сервера задан `1`.                                                     |
| `telemetry.entity_interval_ticks`          | Частота NPC, боссов, монет и пилонов в игровых тиках. Для локального сервера задан `1`.                                        |
| `telemetry.map_capture_interval_ticks`     | Частота захвата цветной карты вокруг игроков.                                                                                  |
| `telemetry.world_scan_interval_ticks`      | Частота обработки чанков сканером мира.                                                                                        |
| `telemetry.map_tile_update_interval_ticks` | Частота отправки изменённых тайлов и стен. Хуки отслеживают разрушение, размещение и взрывы.                                   |
| `telemetry.browser_live_poll_interval_ms`  | Интервал компактного запроса браузера. По умолчанию 50 мс для плавного движения маркеров.                                      |
| `telemetry.browser_map_poll_interval_ms`   | Интервал получения новых чанков карты браузером. Сейчас 5000 мс.                                                               |
| `telemetry.browser_debug_poll_interval_ms` | Интервал обновления карты при открытых настройках debug. Сейчас 1000 мс.                                                       |

Если страница выключена, сервер возвращает 404. Выключенный раздел скрывается в меню и его данные не запрашиваются при открытии; выключенный слой карты не запускает соответствующий рендер. Для нового слоя добавьте default, запись в `terraria_viewer/web/src/core/modules.ts` и описание здесь. Клиентские настройки отображения хранятся отдельно от серверной конфигурации.

## Сборка интерфейса

Редактируемые исходники находятся в `terraria_viewer/web/src`: TypeScript — в файлах интерфейса и разделов, SCSS — в `styles`. Установите инструменты разработки и соберите статические файлы:

```sh
npm ci
npm run format
npm run check:web
```

Сборка выпускает минифицированные ES-модули и CSS в `terraria_viewer/web/assets`; Python раздаёт их без Node.js в рабочем окружении. Разделы карты, игроков, боссов, сервера и событий остаются отдельными динамическими чанками со своими CSS-файлами.

Состав страниц и отдельных UI-компонентов задаётся конфигурацией приложения; это позволяет отключать ненужные разделы без изменения кода.
