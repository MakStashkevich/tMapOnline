# конфигурация и блоки сайта

этот файл объясняет настройки сервера. YAML – это текстовый формат настроек с отступами: пробелы показывают, к какой группе относится параметр. серверная конфигурация определяет, какие данные собирать и какие функции разрешить. она общая для всех посетителей. масштаб и видимость слоёв каждый браузер хранит отдельно в `localStorage`.

файл читает `tmaponline/config.py`. это код, который проверяет настройки перед запуском. если параметр пропущен, tMapOnline возьмёт для него значение по умолчанию. после правки перезапусти сервис, иначе он продолжит работать со старыми настройками.

```yaml
site:
  world_map:
    route_history_days: 7 # Длительность истории маршрутов в днях (1–365)
  pages:
    world_map: { enabled: true }
  sections:
    world: true
    players: true
    bosses: true
    server: true
    activity: true
  modules:
    world_map.exploration: true
    world_map.entities: true
```

здесь показана группа `site` – настройки веб-карты и разделов. ниже в файле есть ещё группы `storage` и `telemetry`. после двоеточия у каждой настройки стоит её значение: `true` включает возможность, `false` выключает. число `7` означает, что карта будет запрашивать последние семь дней маршрута. следи за пробелами в начале строк: отступ показывает, к какой группе относится настройка.

когда в карточке игрока включена «История маршрута», карта сама запросит сохранённые точки за период `site.world_map.route_history_days`. укажи здесь число дней от 1 до 365.

ниже – параметры хранения истории и частоты обновлений. телеметрия – это сведения, которые мод автоматически передаёт сервису во время игры.

```yaml
storage:
  death_retention_seconds: 3600 # 0 — хранить смерти без ограничения
  event_retention_seconds: 2592000 # 30 дней; 0 — без ограничения по сроку
  event_max_entries: 5000 # верхний предел количества событий
telemetry:
  player_position_interval_ticks: 6 # Позиции игроков, 6 тиков ≈ 100 мс
  entity_interval_ticks: 6 # NPC, боссы, монеты и пилоны
  map_capture_interval_ticks: 30 # Цветные данные карты вокруг игроков
  map_tile_update_interval_ticks: 1 # Изменившиеся тайлы и стены, включая взрывы
  map_pings_from_players_to_web: true # Показывать на карте пинги, отправленные игроками
  map_pings_from_web_to_players: true # Передавать игрокам пинги с веб-карты
  initial_world_scan_enabled: true # Полный скан мира при старте tMapOnline
  world_scan_interval_ticks: 1 # Пауза между обработкой чанков сканера
  browser_live_poll_interval_ms: 50 # Частота лёгкого запроса живых данных
  browser_overview_poll_interval_ms: 250 # Частота live-обновлений при обзоре всей карты
  browser_map_poll_interval_ms: 5000 # Частота получения обновлений карты
  browser_debug_poll_interval_ms: 1000 # Частота карты при открытых настройках debug
```

срок очистки применяется и к уже сохранённым смертям. для каждого события смерти мод отправляет устойчивый ID и ждёт подтверждения Python-сервиса; при обрыве соединения событие остаётся в очереди и передаётся повторно.

журнал событий автоматически очищается при запуске и после каждой новой записи: удаляются записи старше `storage.event_retention_seconds`, затем остаются не более `storage.event_max_entries` последних записей. даже при сроке `0` действует ограничение по количеству.

часть частот задана в игровых тиках. тик – один шаг игры; при 60 тиках в секунду шесть тиков занимают примерно 100 миллисекунд. tMapOnline передаёт эти значения моду. частоты браузера заданы в миллисекундах: 1000 мс – это одна секунда. саму большую карту браузер загружает отдельно, а позиции, объекты и небольшие изменения блоков получает через `/api/world-map/live`. так ему не приходится каждый раз скачивать карту целиком.

все доступные настройки и значения по умолчанию перечислены в `config.example.yaml`. путь к рабочему файлу передаётся команде через `--config`, например `tmaponline --config config.local.yaml serve`.

| ключ                                          | назначение                                                                                                                             |
| --------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `site.pages.world_map.enabled`                | включает веб-карту tMapOnline.                                                                                                         |
| `site.sections.*`                             | включает вкладки данных: мир, игроки, боссы, сервер и нагрузка. данные вкладки запрашиваются при её открытии.                          |
| `site.modules.world_map.*`                    | включает отдельные слои карты: исследование, маршруты, игроки, сущности, монеты, пилоны, точку появления, подсказки и отладку.         |
| `storage.death_retention_seconds`             | сколько секунд хранить метки смертей; `0` отключает автоматическую очистку. по умолчанию 3600.                                         |
| `storage.event_retention_seconds`             | срок хранения событий журнала в секундах; `0` отключает очистку по сроку. по умолчанию 2592000 (30 дней).                              |
| `storage.event_max_entries`                   | максимальное количество последних записей журнала. по умолчанию 5000.                                                                  |
| `telemetry.player_position_interval_ticks`    | частота позиций игроков в игровых тиках. для локального сервера задан `1`.                                                             |
| `telemetry.entity_interval_ticks`             | частота NPC, боссов, монет и пилонов в игровых тиках. для локального сервера задан `1`.                                                |
| `telemetry.map_capture_interval_ticks`        | частота захвата цветной карты вокруг игроков.                                                                                          |
| `telemetry.initial_world_scan_enabled`        | включает полный начальный скан мира. выключите для проверки обновлений карты от передвижения игроков и изменений тайлов.               |
| `telemetry.world_scan_interval_ticks`         | частота обработки чанков сканером мира.                                                                                                |
| `telemetry.map_tile_update_interval_ticks`    | частота отправки изменённых тайлов и стен. хуки отслеживают разрушение, размещение и взрывы.                                           |
| `telemetry.map_pings_from_players_to_web`     | передавать пинги игроков на веб-карту.                                                                                                 |
| `telemetry.map_pings_from_web_to_players`     | отправлять пинги, созданные на веб-карте, игрокам на сервере.                                                                          |
| `telemetry.browser_live_poll_interval_ms`     | интервал компактного запроса браузера. по умолчанию 50 мс для плавного движения маркеров.                                              |
| `telemetry.browser_overview_poll_interval_ms` | интервал live-запросов при отдалённой карте. в этом режиме маркеры перемещаются скачком, без покадровой анимации. по умолчанию 250 мс. |
| `telemetry.browser_map_poll_interval_ms`      | интервал получения новых чанков карты браузером. сейчас 5000 мс.                                                                       |
| `telemetry.browser_debug_poll_interval_ms`    | интервал обновления карты при открытых настройках debug. сейчас 1000 мс.                                                               |

если страница выключена, её адрес ответит `404` – значит, такой страницы сейчас нет. выключенный раздел исчезает из меню и не загружает данные. выключенный слой не рисуется на карте. чтобы добавить новый слой, укажи его настройку по умолчанию, зарегистрируй в `tmaponline/web/src/core/modules.ts` и добавь описание в этот документ. настройки, которые пользователь переключает в браузере, в этот YAML-файл не записываются.

## сборка интерфейса

редактируемые файлы веб-интерфейса лежат в `tmaponline/web/src`: поведение написано на TypeScript, внешний вид – в SCSS внутри `styles`. чтобы собрать готовую версию интерфейса, выполни:

```sh
npm ci
npm run format
npm run check:web
```

сборка выпускает минифицированные ES-модули и CSS в `tmaponline/web/assets`; Python раздаёт их без Node.js в рабочем окружении. разделы карты, игроков, боссов, сервера и событий остаются отдельными динамическими чанками со своими CSS-файлами.

`npm ci` устанавливает именно те версии инструментов, которые записаны в lock-файле. `npm run format` приводит исходники к принятому в проекте формату. `npm run check:web` проверяет веб-код и собирает интерфейс. результат попадёт в `tmaponline/web/assets`; это готовые файлы, их создаёт сборка. менять нужно исходники в `src` или файлы ресурсов в `static`.
