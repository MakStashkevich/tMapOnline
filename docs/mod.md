# серверный мод tMapOnline

мод называется `tMapOnline`. он запускается внутри серверного tModLoader; игрокам отдельно скачивать его не нужно. мод передаёт данные из игры веб-сервису, а Map Ping доставляет в обе стороны.

## что делает мод

мод не рисует карту и не запускает сайт. он читает игровые данные – например, где сейчас находится игрок – и отправляет их программе tMapOnline. та сохраняет данные и показывает их в браузере. Map Ping тоже работает в обе стороны: поставь отметку в браузере – она появится в игре; поставь её в игре – она появится в браузере.

## назначение и границы

мод и tMapOnline обмениваются сообщениями через TCP-соединение на адресе `127.0.0.1`. это адрес самого компьютера: к этому порту не подключаются снаружи. каждое сообщение записано отдельной строкой в формате JSON. мод не является веб-сервером и не меняет настройки браузера.

игровые объекты безопасно читать и менять только во время игрового цикла – когда tModLoader обновляет мир. для сетевых задач мод использует уже подготовленный текст сообщения, а не обращается к миру из другой задачи.

`TMapOnlineSystem` управляет запуском и остановкой мода. он подключает обработчики игровых событий, запускает остальные части мода, регулярно готовит snapshot (снимок текущего состояния), принимает Map Ping и закрывает соединение при остановке.

| обязанность                                                             | компонент                                          |
| ----------------------------------------------------------------------- | -------------------------------------------------- |
| TCP listener, клиенты, JSONL, подтверждение snapshot и входящие команды | `TelemetryStreamServer`                            |
| снимок NPC и сущностей мира                                             | `WorldEntitySnapshotBuilder`                       |
| выгрузка внешнего вида игрока и текстур мода                            | `PlayerAppearanceSnapshotBuilder`                  |
| сканирование карты и изменения RGB/RGBA тайлов                          | `WorldMapScanner`, `MapTileDataCapture`            |
| названия тайлов/стен и локализация                                      | `MapTileNameCatalog`                               |
| обнаружение области карты игрока                                        | `PlayerMapChangeRevealer`                          |
| ванильные флаги побед и legacy-счётчики                                 | `BossProgressSnapshotReader`, `BossVictoryTracker` |
| специфичная интеграция Calamity                                         | `CalamityBossProgressAdapter`                      |

в таблице перечислено, за что отвечает каждый класс. RGB – цвет пикселя: красный, зелёный и синий. RGBA добавляет к ним прозрачность. `CalamityBossProgressAdapter` нужен только для поддержки Calamity; остальная логика прогресса боссов от него не зависит.

имена в таблице совпадают с исходниками. если меняешь работу с игровым миром, оставляй чтение и изменение объектов внутри игрового цикла. сеть может работать отдельно, но только с уже подготовленными сообщениями.

## транспорт и надёжность

- по умолчанию listener (программа, которая ждёт сетевое соединение) слушает только `127.0.0.1:38762`; настройки сервера: `server.telemetry_host` и `server.telemetry_port`.
- снимки — JSON Lines, schema version `1`. каждая строка содержит `snapshotId`; tMapOnline подтверждает принятый snapshot тем же TCP соединением.
- события смерти имеют устойчивый ID, повторяются до подтверждения и ограничиваются `storage.death_retention_seconds`.
- клиент tMapOnline переподключается при разрыве. Listener хранит последнее состояние, чтобы новый клиент сразу получил актуальный snapshot.
- Web Map Ping отправляется как команда с координатами тайлов; мод выполняет игровую рассылку подключённым игрокам. игровые Map Ping входят в обратный поток как события с координатами тайлов.
- клиентские отображаемые настройки не пересылаются в мод. интервалы и направленность пингов задаются конфигурацией запуска сервера.

важно не перепутать направление соединения: мод открывает порт и ждёт, а Python-сервис подключается к нему. после подключения оба могут отправлять сообщения: сервис шлёт Map Ping и подтверждения, мод – новые снимки и игровые события.

схему и endpoint-ы см. [telemetry.md](telemetry.md). если поле меняет смысл или тип, используйте новую версию схемы и переходный период совместимости; не меняйте v1 молча.

## сборка

команду нужно запускать из корневой папки проекта. на macOS можно указать папку установленного tModLoader через переменную `TML_ROOT`:

```sh
TML_ROOT="/path/to/tModLoader" python3 tools/build-mod.py
```

замени `/path/to/tModLoader` на путь к установленной игре. скрипт соберёт C#-проект и положит готовый пакет в `dist/tMapOnline.tmod`. для сборки используется отдельная временная папка, поэтому настройки твоего профиля не меняются. скрипт не устанавливает мод и не трогает файлы работающего сервера. версия tModLoader для сборки должна совпадать с версией сервера.

чтобы сервер увидел мод, скопируй `.tmod` в папку `Mods` его профиля и добавь ID в `Mods/enabled.json` – список включённых модов. мод загрузится при следующем запуске сервера. перед этим проверь, что игроки вышли, чтобы не оборвать им игру.

## изменения мода

1. найди нужный обработчик события в `TMapOnlineSystem`. если там накапливается много логики, вынеси её в отдельный класс с одной понятной задачей.
2. проследи сообщение целиком: кто его отправляет и кто принимает в Python-сервисе.
3. читай Terraria API в игровом цикле. сетевой задаче передавай уже подготовленное сообщение.
4. для важного события добавь уникальный ID и повторную отправку, пока сервис не подтвердит получение.
5. собери мод через `python3 tools/build-mod.py` под ту версию tModLoader, с которой он будет работать.
6. не копируй `.tmod` в профиль работающего сервера и не перезапускай его без отдельного запроса на установку и запуск.

здесь «обработчик» – код, который запускается при событии игры. например, при изменении блока. уникальный ID помогает сервису понять, какое событие он уже принял. благодаря этому повторная отправка не создаст лишнюю копию.
