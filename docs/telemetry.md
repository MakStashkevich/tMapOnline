# Телеметрия и API

## Поток мода

Мод подключается к `server.telemetry_host:server.telemetry_port` и отправляет JSONL, по одной записи JSON на строку. `schemaVersion: 1` включает состояние сервера, мира, игроков, NPC/bosses, объекты карты и прогресс. Python клиент автоматически переподключается и игнорирует некорректную строку, сохраняя соединение.

Изменяйте payload совместимо: добавляйте optional поля; breaking changes оформляйте новой версией схемы и поддерживайте обе версии на время перехода. Сырые сообщения не должны содержать секреты.

## HTTP endpoints

| Endpoint                                                   | Назначение                                                       |
| ---------------------------------------------------------- | ---------------------------------------------------------------- |
| `GET /api/status`                                          | Сводное состояние сервера, игроков, боссов и истории             |
| `GET /api/world-map`                                       | Снимок карты/слоёв мира                                          |
| `GET /api/world-map?since=...`                             | Дельта обновлений карты                                          |
| `GET /api/world-map/tile-info?x=...&y=...`                 | Локализованное описание блока/стены                              |
| `GET /api/world-map/exploration?id=...&world=...`          | Изображение исследования игрока                                  |
| `POST /api/world-map/import-player-map?id=...`             | Импорт `.map` со страницы debug; объединяет новые открытые тайлы |
| `POST /api/world-map/export-player-map?id=...`             | Экспорт `.map` из сохранённой информации                         |
| `DELETE /api/world-map/import-player-map?id=...&world=...` | Очистка только импортированной части карты                       |
| `GET /api/resource-history?days=...`                       | История ресурсов сервера                                         |
| `GET /api/wiki-cache?url=...`                              | Проксирование разрешённых ресурсов wiki.gg с кэшированием        |
| `GET /healthz`                                             | Локальная проверка доступности HTTP сервера                      |
| `GET /api/site-config`                                     | Feature flags интерфейса                                         |

Static assets находятся в `/assets/`; изображения сущностей выдаются из API-каталогов хранилища.
