# Локальный перенос и проверка

1. Убедитесь, что старый сервер остановлен и сохранение мира завершено. Отключите старый telemetry mod только после резервной копии списка mods и `.tmod`.
2. Установите проект в отдельное окружение Python. Каталог данных по умолчанию — `~/Library/Application Support/TerrariaWorldViewer`; до первого запуска сделайте резервную копию.
3. Соберите новый tModLoader mod соответствующей установленной версии; сначала проверьте его на тестовой копии мира.
4. Запустите Viewer `serve`, проверьте `/healthz`, `/api/site-config`, `/api/status`, `GET /api/world-map` и synthetic telemetry test.
5. Запустите локальный игровой сервер с новым модом. Сверьте online players, карту, историю и NPC entities, затем убедитесь, что мир сохраняется.
6. Если что-то не прошло, остановите новую сборку, восстановите сохранённые `.tmod` и список mods, затем запустите legacy оркестратор.

Не удаляйте старые процессы или пользовательские файлы при миграции.
