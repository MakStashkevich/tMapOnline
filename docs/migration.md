# обновление tMapOnline

я продолжаю развивать tMapOnline как веб-карту для нашей игры с друзьями. При обновлении я сохраняю данные мира, историю игроков и прогресс боссов.

В этом документе собраны шаги обновления веб-карты, backend и серверного мода `tMapOnline`.

## состав проекта

- Python-пакет и команда запуска называются `tmaponline`.
- LaunchAgent запускает команду `tmaponline` из виртуального окружения проекта.
- Исходники серверного мода и его ID называются `tMapOnline`.
- Новый артефакт сборки называется `tMapOnline.tmod`.

После изменения исходников соберите новый пакет и установите его в профиль tModLoader. Перед заменой мода проверьте подключённых игроков и сохраните резервную копию мира и списка включённых модов.

## пользовательские данные

По умолчанию данные веб-карты и мода находятся в `~/Library/Application Support/tMapOnline`. Там лежат данные миров, история игроков, кэш изображений и `boss-victories.json`. Не удаляйте этот каталог при обновлении. При изменении `storage.data_dir` сначала перенесите содержимое и проверьте, что новая установка его читает.

## установка и запуск обновлённой версии

1. Создайте или активируйте Python-окружение проекта и установите пакет из checkout: `python3 -m pip install -e .`.
2. Запустите карту командой `tmaponline --config config.local.yaml serve` или `tmaponline --config config.local.yaml run`.
3. Соберите мод под установленную версию tModLoader: `TML_ROOT="/path/to/tModLoader" python3 tools/build-mod.py`.
4. Проверьте полученный `dist/tMapOnline.tmod` на тестовом профиле или копии мира. Сборка не устанавливает мод автоматически.
5. Перед заменой мода на основном сервере убедитесь, что в мире нет игроков. Сохраните мир, старый `.tmod` и исходный список включённых модов.
6. Установите `tMapOnline.tmod` в серверный профиль, включите мод с новым ID и перезапустите сервер только в согласованное безопасное окно.
7. Проверьте `/healthz`, `/api/site-config`, `/api/status`, карту, live-телеметрию и приём/отправку Map Ping.

## откат

Если новая сборка не запускается, остановите её штатно и восстановите предыдущий `.tmod`, список включённых модов и сборку сервиса. Каталог данных tMapOnline при откате не удаляйте.
