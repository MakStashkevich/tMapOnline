# оновлення tMapOnline

цей документ описує оновлення вебкарти, Python-сервісу (backend) і серверного моду `tMapOnline`. Оновлення замінює програму, але не має видаляти збережений світ, історію гравців або прогрес босів.

## склад проєкту

- Python-пакет і команда запуску називаються `tmaponline`.
- У macOS LaunchAgent — системна служба, яка під час входу може запускати `tmaponline` із віртуального середовища проєкту.
- Вихідний код серверного моду та його ID називаються `tMapOnline`.
- Новий артефакт збірки називається `tMapOnline.tmod`.

Після зміни вихідного коду збери новий пакет і встанови його в профіль tModLoader. Профіль — окрема інсталяція tModLoader зі своїми модами й світами. Перед заміною моду перевір, що гравці від’єдналися, і створи резервні копії світу та списку ввімкнених модів.

## дані користувача

Типово дані вебкарти й моду містяться в `~/Library/Application Support/tMapOnline`. Символ `~` означає домашню папку поточного користувача. Тут зберігаються дані світів, історія гравців, кеш зображень і `boss-victories.json` — файл із прогресом перемог над босами. Не видаляй цей каталог під час оновлення. Якщо змінюєш `storage.data_dir`, спочатку перенеси файли в нове місце й перевір, що програма їх бачить.

## установлення та запуск оновленої версії

Виконуй команди з кореневої папки проєкту. Python-оточення — окрема папка з бібліотеками tMapOnline, щоб вони не змішувалися з іншими програмами на комп’ютері.

1. Створи або активуй оточення й установи пакет із поточної папки: `python3 -m pip install -e .`. Прапорець `-e` указує Python використовувати вихідний код безпосередньо звідси, тож повторно збирати пакет після змін не потрібно.
2. Запусти карту командою `tmaponline --config config.local.yaml serve` або `tmaponline --config config.local.yaml run`. `--config` задає файл параметрів. `serve` запускає лише вебсервіс, а `run` також запускає ігровий сервер, якщо його вказано в конфігурації.
3. Збери мод для встановленої версії tModLoader: `TML_ROOT="/path/to/tModLoader" python3 tools/build-mod.py`.
4. Перевір `dist/tMapOnline.tmod` у тестовому профілі або копії світу. Це готовий файл моду. Збірка лише створює його й автоматично не встановлює в серверний профіль.
5. Перед заміною моду переконайся, що гравці вийшли. Збережи копії світу, старого `.tmod` і списку ввімкнених модів.
6. Скопіюй `tMapOnline.tmod` у профіль сервера, увімкни мод і перезапусти сервер у безпечний час, коли гравців немає.
7. Відкрий `/healthz`, щоб перевірити відповідь сервісу; `/api/site-config` — увімкнені функції; `/api/status` — стан сервера. Потім перевір карту, свіжі ігрові дані та Map Ping в обох напрямках.

## відкат

Якщо нова збірка не запускається, штатно зупини її й віднови попередній `.tmod`, список ввімкнених модів і попередню збірку сервісу. Відкат повертає збережену робочу версію. Не видаляй каталог даних tMapOnline.
