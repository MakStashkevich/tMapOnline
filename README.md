`tMapOnline` начался с вопроса друга: можно ли видеть на карте сразу всё, что открыли все игроки, а не только то, что исследовал ты сам.

мы сначала играли в обычную Terraria – на серверах без модов. мой друг очень любил исследовать мир: открывать новые биомы и места, искать мобов и строить дома. он часто спрашивал, можно ли сложить открытия всей команды в одну общую карту. я подумал, что это было бы удобно, и решил попробовать сделать веб-карту, которая будет собирать исследованные области и перемещения игроков.

но первой версией была даже не карта. это была простая веб-страница с состоянием сервера: сколько он работает, какую нагрузку создаёт и сколько памяти потребляет. мне хотелось понимать, что происходит с сервером, пока мы играем. потом появились сведения о боссах и игроках, их внешнем виде и броне. я разбирался, как получать игровые спрайты и показывать их в браузере. и уже после этого на странице стала появляться сама карта.

когда мы перешли на tModLoader и моды, я добавил серверный мод `tMapOnline`. он читает доступное из игрового процесса состояние мира и передаёт его веб-сервису: карту, позиции и внешний вид игроков, NPC, боссов и другие события. так веб-карта постепенно превратилась из страницы мониторинга в отдельное окно в нашу игру.

сейчас я могу открыть карту с компьютера или телефона и посмотреть, где находятся друзья, что происходит в мире и с кем они сражаются. если мы с другом разговариваем в Discord, а он играет, мне не обязательно запускать Terraria. он может спросить, где находится улей, а я отмечу место двойным нажатием на карте. через Map Ping отметка появится у него в игре. для меня в этом и есть главная ценность проекта: можно оставаться частью совместной игры, даже когда ты сам сейчас не зашёл на сервер.

я старался сделать карту похожей на Terraria и не забывать про устройства, на которых её будут открывать. поэтому карта собирается из готовых PNG-чанков разных уровней детализации, а видимые области и маркеры подгружаются отдельно. я много внимания уделял зуму, кэшированию и работе на телефонах, чтобы карта не превращалась в тяжёлую картинку, которую невозможно двигать.

это мой личный проект, выросший из нашей игры с друзьями. я открываю его исходники, чтобы другие игроки могли поставить такую карту на свой сервер, переделать её под себя или построить на её основе свой проект.

У каждого карта может быть настроена по-своему: выбор слоёв и другие настройки отображения я сохраняю в браузере, в `localStorage`. Они не меняют то, что видят остальные. Адреса, частоту телеметрии, срок хранения данных и доступные функции я задаю отдельно — в YAML-конфиге сервера.

## что показывает карта

- полноразмерную карту мира с пирамидой PNG-фрагментов нескольких уровней детализации;
- исследованные области, маршруты игроков за срок из конфигурации и динамически обновляемые тайлы;
- игроков, головы NPC и боссов, пилоны, монеты, точку появления, места смерти и Map Ping;
- затемнение неразведанных участков по маскам маршрутов, с плавным краем и влиянием освещения;
- локальные игровые фоновые текстуры, пиксельные меню, подсказки и карту на мобильных устройствах;
- состояние сервера, историю игроков и сессий, прогресс боссов, нагрузку и сгруппированные события.

## запуск

Требуются Python 3.9+, установленный tModLoader для режима совместного запуска и Node.js только для сборки интерфейса.

```sh
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install -e .
cp config.example.yaml config.local.yaml
```

Запустить веб-карту tMapOnline и локальный игровой сервер:

```sh
tmaponline --config config.local.yaml run
```

Запустить только веб API и карту tMapOnline, например когда Terraria-сервер управляется отдельно:

```sh
tmaponline --config config.local.yaml serve
```

Откройте адрес из `server.host` и `server.port` (по умолчанию `http://127.0.0.1:8765`). Режим `run` запускает сервер, указанный в конфиге. Он не останавливает посторонний процесс, который уже занял игровой порт.

### серверный мод

Мод необходим на серверном экземпляре tModLoader. Игрокам устанавливать его не нужно. Он запускает TCP listener только на loopback-интерфейсе и передаёт веб-сервису tMapOnline состояние мира; входящие Map Ping от tMapOnline пересылаются подключённым игрокам.

```sh
TML_ROOT="/path/to/tModLoader" python3 tools/build-mod.py
```

Сборщик использует изолированный профиль tModLoader и записывает пакет в `dist/tMapOnline.tmod`, не перезаписывая установленный мод работающего сервера. Скопируйте пакет в Mods серверного профиля, включите `tMapOnline` в списке модов и перезапустите сервер в безопасное время. Не перезапускайте мир с подключёнными игроками.

### сборка веба

```sh
npm ci
npm run build
```

Проверки разработчика: `npm run typecheck`, `npm run check:python`, `npm run check:web` и `npm run check:all`. Сгенерированные файлы в `tmaponline/web/assets` обновляются сборкой, исходники интерфейса находятся в `tmaponline/web/src`.

## конфигурация и данные

Основной пример: [config.example.yaml](config.example.yaml). Полное описание серверных параметров: [docs/configuration.md](docs/configuration.md).

Пользовательские переключатели игроков, маршрутов, NPC, боссов, пилонов и анимации, а также плавность и частота отображения сохраняются в браузере. Сервер не получает эти предпочтения.

По умолчанию данные tMapOnline хранятся в `~/Library/Application Support/tMapOnline`: здесь находятся кэш карты, история игроков, импортированные карты и прогресс боссов. Путь можно изменить параметром `storage.data_dir` в серверном YAML-конфиге.
